# 🎓 Campus Saathi

> **Your campus companion — everything you need, all in one place.**

Campus Saathi is a modern student-focused campus platform designed to bring important college resources, notices, events, clubs, contacts, and campus information together in one convenient place.

🌐 **Live Demo:** https://campus-saathi-app.vercel.app/

---

## ✨ Features

- 🗺️ **Campus Map** — Find important locations around campus
- 📢 **Notices** — Stay updated with important announcements
- 📅 **Events** — Discover upcoming campus events and activities
- 👥 **Clubs** — Explore student clubs and communities
- 📞 **Contacts** — Quickly find important campus contacts
- 🏫 **College Information** — Access useful college-related information
- 📱 **Responsive Design** — Works smoothly across different screen sizes
- ⚡ **Fast & Modern UI** — Built with a modern frontend stack
